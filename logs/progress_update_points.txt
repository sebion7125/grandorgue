Progress‑Update‑Punkte (Extrahiert aus src/grandorgue)

Hinweis: Dies ist eine statische Extraktion der Code‑Stellen, an denen die Progress‑Anzeige aktualisiert oder deren Range gesetzt wird. Laufzeit‑Zeitstempel müssen durch tatsächliche Logdateien gewonnen werden (z.B. durch Ausführen der Binary und Grep nach "Progress:" / "Timing:"). Unten: Datei:Zeile (kontext) + was an die Progress‑UI gesendet wird.

1) Parsing sample set definition file
- Datei: src/grandorgue/GOOrganController.cpp
- Stelle:
    if (dlg) dlg->ResetRange(100, 0, 4, _("Parsing sample set definition file"));
    ...
    bool ok = odf_ini_file.ReadWithProgress(
      opened.get(),
      _("Parsing sample set definition file"),
      [dlg](unsigned pc, const wxString &msg) {
        dlg->Update(pc, msg);
      });
- Bedeutung: ReadWithProgress liefert Prozentwerte 0..100; ResetRange mappt diese in das Fenster 0%..4% der Gesamt‑Progressbar. Laufzeit‑Updates: dlg->Update(pc, msg) mit pc in 0..100.

4) Panels (GUI) — initial panel + loop
- Datei: src/grandorgue/GOOrganController.cpp
- Stelle (GUI_GAP_TRACER path + non‑tracer identical logic):
    m_panels.push_back(new GOGUIPanel(this));
    if (dlg) dlg->ResetRange(totalPanels, 35, 40, _("Loading panels"));
    for (unsigned i = 0; i < NumberOfPanels; i++) {
      buffer.Printf(wxT("Panel%03d"), i + 1);
      m_panels.push_back(new GOGUIPanel(this));
      if (dlg) {
        wxString msg = _("Loading panel: ");
        msg += buffer;
        msg += wxString::Format(_(" (%u/%u)"), (unsigned)m_panels.size(), totalPanels);
        if (!dlg->Update(i + 1, msg))
          throw GOLoadAborted();
      } else {
        wxLogMessage(wxString::Format("Progress: Loading panels (%u/%u)", (unsigned)m_panels.size(), totalPanels));
      }
      m_panels[i + 1]->Load(cfg, buffer);
    }
- Bedeutung: ResetRange mit units = totalPanels (not percent) mapped to 35%..40%. Update called with unit = i+1 and msg "Loading panel: PanelNNN (x/y)". Wenn dlg==null, es gibt alternativ wxLogMessage mit "Progress: Loading panels ...".
